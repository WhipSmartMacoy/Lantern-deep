LANTERN DEEP - COMPLETE SOURCE AND ASSETS (game v0.33, core milestone 4)
========================================================================

game\                The game
  src\               Game code in C (game.c pulls in the rest):
                       game.c    rules, combat, saves, settings, save states
                       world.c   map generation, town, environment drawing
                       render.c  world / HUD drawing      menu.c  menus and shops
                       items.c   loot, gems               sound.c sound
                       gfx.c     drawing helpers          gpu.c   Lantern GPU commands + reference model
                       art_data.h  all art converted to C (generated by tools\gen_art.py)
  plat\              One "main" per platform:
                       pocket_main.c  Analogue Pocket     wasm_main.c  browser (PC test)
                       host_main.c    test harness        gpu_selftest.c / gputest_main.c  hardware tests
  art\               Every sprite as a PNG (heroes, monsters, items, tiles, buildings)
  assets\            The 3D models (.glb) the sprites are rendered from
  baker\, tools\     Art pipeline (models -> sprites -> art_data.h), the RISC-V emulator (rv32emu.c)
  web\template.html  The page the browser version is built into
  hw\rtl\            Copy of the Lantern GPU hardware source (also inside core\)
  build_pocket.sh    Builds the Pocket program (boot.bin). Needs clang with RISC-V support + lld.
  build_web.sh       Builds the browser version (index.html). Needs clang with WebAssembly support.
                     Both scripts expect the core folder at /home/claude/ext/openfpga-litex -
                     change that path at the top if you build somewhere else (Linux / WSL).

core\                The custom Pocket core
  openfpga-litex\    Fork of agg23's openFPGA RISC-V core (MIT licence) with the Lantern GPU:
                       target\pocket\lantern_gpu.sv        the drawing engine (ours)
                       target\pocket\core_top.sv           core wiring (modified)
                       target\pocket\apf_wishbone_master.sv  save-state memory window (modified)
  BUILD_LANTERN_CORE.bat   Builds the core with Quartus Prime Lite 21.1.1 and makes the SD folder
  SD_template\       Core definition files + the current game (Assets\lanterndeep\common\boot.bin)
  tools\             Helper for the .bat (bitstream conversion)

Third-party parts: agg23's openfpga-litex (MIT), LiteX and VexRiscv inside it (their own licences),
Analogue's APF framework files in core\openfpga-litex\platform\pocket.
