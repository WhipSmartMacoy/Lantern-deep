# Lantern Deep

An endless isometric dungeon crawler (Diablo / Torchlight style) for the Analogue Pocket, running on its own custom core with a hardware GPU ("Lantern GPU"). Also plays in a browser.

**▶ Play it now (phone or computer): https://whipsmartmacoy.github.io/Lantern-deep/**

On a phone, use the on-screen buttons. On a computer, use the keyboard or a game controller. Your heroes are saved in that browser.

| Folder | What's in it |
|---|---|
| `Pocket SD/` | Everything that goes on the Pocket's SD card (core + game) |
| `Pocket Updater/` | The "Update files?" helper that copies `Pocket SD` to the Pocket |
| `Lantern Deep - PC test.html` | Play the game in a browser |
| `Source/game/` | Game code (C), art, 3D models, tools |
| `Source/core/`, `Core build (M4)/` | The Pocket core (FPGA) and its build scripts |
| `Asset Checklist.md`, `Asset List.csv` | Every picture in the game, for Lantern Forge |

Save files are never stored here.
